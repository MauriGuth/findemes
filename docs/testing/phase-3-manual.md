# Phase 3 — manual test checklist (email and bills)

**Before starting**

- Postmark: create an account and a server; in the server's **Inbound** stream copy the inbound address (`xxxx@inbound.postmarkapp.com`) and set the webhook URL to `https://USER:PASSWORD@findemesapi-production.up.railway.app/inbound/postmark` (with "Include raw email content" off).
- Railway → API → Variables: `INBOUND_EMAIL_ADDRESS` (that address), `INBOUND_WEBHOOK_USER`, `INBOUND_WEBHOOK_PASSWORD` (`openssl rand -base64 32`). The deploy shows the Pre-deploy step with migration `20261014200000_phase3_email_bills`.
- The app updates itself (OTA). If it does not show "Tus correos" in Ajustes, close it and open it twice.
